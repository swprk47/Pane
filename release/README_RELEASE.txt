Pane 1.0.0  -  Windows 11용 동영상 플레이어
==========================================

설치 프로그램으로 받은 경우 (Pane-1.0.0-setup.exe)
------------------------------------------------
- setup 파일을 실행하고 안내를 따르면 됩니다. 관리자 권한은 필요 없고 내 계정에만 설치됩니다.
- 시작 메뉴에 Pane이 생기고, 설치 중에 바탕화면 바로가기를 선택할 수 있습니다.
- "영상 파일의 연결 프로그램 목록에 Pane 등록"을 선택하면(기본 선택) 영상 파일을 우클릭한 뒤
  [연결 프로그램] -> [Pane] 으로 열 수 있고, [설정] -> [앱] -> [기본 앱]에서 Pane을 기본 플레이어로
  고를 수도 있습니다. (이미 쓰던 기본 플레이어를 설치 프로그램이 마음대로 바꾸지는 않습니다.)
- 새 버전은 새 setup 파일을 실행하면 이전 버전 위에 그대로 설치됩니다 (설정 유지, 실행 중이면 자동으로 닫음).
- 제거는 [설정] -> [앱] -> [설치된 앱] 에서 Pane을 제거합니다. 제거할 때 이어보기 위치 같은
  설정을 함께 지울지 물어봅니다 (기본: 지우지 않음).

압축(zip)으로 받은 경우 - 실행 방법
-----------------------------------
1. 압축을 풀고 Pane 폴더를 원하는 곳에 둡니다 (설치 불필요).
2. Pane.exe 를 실행합니다.
3. 영상 파일을 창에 끌어다 놓거나, 영상 화면을 클릭해서 파일을 엽니다.
   (영상 파일을 Pane.exe 위로 끌어다 놓아도 열립니다.)

* "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] -> [실행] 을 누르세요.
  아직 코드 서명을 하지 않은 프로그램이라 나오는 경고입니다.

필요한 환경
-----------
- Windows 11 (64비트)
- 그래픽 드라이버가 최신이면 영상 재생이 더 가볍습니다 (GPU 하드웨어 디코딩).

주요 기능
---------
- 0.05x 단위 정밀 배속 (왼쪽 아래 배속 버튼 -> 프리셋 최대 6개 + 슬라이더)
- 영상 위에 겹쳐 뜨는 컨트롤 (마우스를 2.5초 안 움직이면 사라짐)
- 영상 한가운데를 클릭하면 재생/일시정지, 더블클릭하면 전체화면
- 이어보기 (파일을 다시 열면 보던 위치부터)
- PIP(항상 위 작은 창), 자막 자동 로드, 1프레임 이동, 화면 캡처
- I 키: 재생 정보 (코덱, GPU/CPU 디코딩 여부, 해상도, 프레임, 버려진 프레임)
- 우클릭: 메뉴 (파일 열기, 배속, 자막, 캡처, 재생 정보, PIP, 전체화면, 정보)

단축키
------
Space            재생 / 일시정지
]  [             배속 +0.1 / -0.1       (Shift 와 함께: 0.05)
\  또는 Backspace 배속 1.0x 로 되돌리기
← →              5초 이동                (Shift 와 함께: 1초)
,  .             1프레임 뒤 / 앞         (일시정지 중)
↑ ↓              볼륨 +5 / -5
M                음소거
C                자막 켜기 / 끄기
F 또는 Enter     전체화면
P                PIP 모드
I                재생 정보
Ctrl+O           파일 열기
Ctrl+S           화면 캡처 (바탕화면에 저장)
Esc              패널 닫기 / 전체화면 나가기 / PIP 나가기

설정과 저장 위치
----------------
- 설정(이어보기 위치, 최근 파일, 배속 프리셋, 컨트롤 배치, 볼륨)은 프로그램 폴더가 아니라
  Windows 레지스트리(HKEY_CURRENT_USER\Software\Pane)에 저장됩니다.
- 오류 기록: %LOCALAPPDATA%\Pane\pane.log
  문제가 생기면 이 파일과 우클릭 메뉴의 "Pane 정보"에 나오는 버전을 알려 주세요.

업데이트
--------
설치 프로그램: 새 setup 파일을 실행하면 됩니다.
zip: 새 버전 zip 을 받아서 기존 Pane 폴더에 덮어쓰면 됩니다. 설정은 그대로 유지됩니다.

삭제
----
설치 프로그램으로 설치했다면 [설정] -> [앱] 에서 제거하세요. zip이라면 Pane 폴더를 지우면 됩니다. 설정까지 지우려면 레지스트리 편집기에서
HKEY_CURRENT_USER\Software\Pane 키도 삭제하세요.

알려진 한계 (v1.0)
------------------
- 4K 60fps 영상을 전체화면으로 볼 때 프레임이 약 5~8% 빠질 수 있습니다.
  (창 모드와 일반적인 24~30fps 영상은 문제없습니다.)
- 자막 싱크 조절, 오디오 트랙 선택, 재생 목록(다음 영상 자동 재생)은 아직 없습니다.
- 전체화면으로 들어갈 때 화면이 0.2초쯤 멈칫할 수 있습니다.

문제 해결
---------
- 영상이 안 나오거나 끊기면: 그래픽 드라이버를 업데이트해 보세요. I 키로 재생 정보를
  열어 "디코더"가 GPU 인지 CPU 인지 확인할 수 있습니다.
- 실행이 안 되면: 압축을 완전히 푼 폴더에서 실행했는지 확인하세요
  (zip 안에서 바로 실행하면 안 됩니다).
