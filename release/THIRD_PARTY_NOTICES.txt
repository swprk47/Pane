   Video playback engine, including FFmpeg and the other libraries it is built with.
   Build in this program:  mpv v0.41.0-1092-g3186d369f  (FFmpeg N-127117-g98e92563a), the Windows
   build of https://github.com/shinchiro/mpv-winbuild-cmake (its releases and build scripts name the
   exact source revision of every library).
   License:  the build is GPL-3.0 (FFmpeg is configured with --enable-gpl --enable-version3; it contains
   GPL libraries such as x264, x265 and libdvdnav).
   Corresponding source:
     mpv      https://github.com/mpv-player/mpv  (commit 3186d369f)
     FFmpeg   https://git.ffmpeg.org/ffmpeg.git  (commit 98e92563a)
     x264     https://code.videolan.org/videolan/x264
     x265     https://bitbucket.org/multicoreware/x265_git
     libdvdnav https://code.videolan.org/videolan/libdvdnav
     everything else: the package list and the scripts at https://github.com/shinchiro/mpv-winbuild-cmake
   On request through https://github.com/swprk47/Pane/issues the maintainer also provides this source.
